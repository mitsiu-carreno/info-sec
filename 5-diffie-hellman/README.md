# Real impelmentation

## Functions
- getP                                  (Server)

- genPublicKey(p, g)                    (Client)

## Example

| Client A     |  Server     | Client B     |

|  | ```const DHServer = require('./real-server-diffiehellman.js')``` |  |

| Number | Meaning |
|----------------|----------------|
| 84d84b1add0661... | Prime number used for this DH run |
| 02 | Generator number used for this DH run |
| 205426821b5851... | Public key generated by Alice and shared to Bob |
| 59f104498c0b19... | Public key generated by Bob and shared to Alice |
| 1322b08454f31a... | Shared secret calculated by Alice and Bob independently |
